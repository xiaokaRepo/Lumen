# lumen-agent

面板只列出服务、发送操作和显示状态。每台要管理的 Linux 机器自己跑 `lumen-agent`。Agent 在那台机器上发现容器，执行启动、停止、日志和镜像操作，读取进程和磁盘，并在那台机器的网页端口上做休眠和唤醒代理。两边用同一枚令牌确认身份。

## 同一局域网

在面板的「主机」页填写 agent 的地址，例如 `http://192.168.1.20:7879`，以及和 agent 相同的 `LUMEN_AGENT_TOKEN`。这种情况下由面板主动连接 agent。

## 和面板在同一台机器上

`docker-compose.yml` 里的 `lumen-agent` 使用主机网络，并设置 `LUMEN_PANEL=http://127.0.0.1:7878`。面板容器不在主机网络里，agent 连的是主机上已经发布出来的 7878 端口。第一次使用时，在「主机」页添加这台机器，地址留空，令牌与 `LUMEN_AGENT_TOKEN` 相同。

## Agent 在面板拨不进去的网络里

设置 `LUMEN_PANEL` 为那台机器能够访问到的面板地址，例如 `http://203.0.113.10:7878`。Agent 会连出到面板，面板再把操作从这条连接送回去。「主机」页的地址可以留空。每台主机使用自己的令牌。

人用浏览器打开面板，走的是面板自己的地址。那条地址不是 agent 的通道。

## 服务的两个地址

每个服务可以记两个打开地址：

- 局域网地址：人在这台机器所在的网络里时使用。
- 远程地址：可选，填这台服务在外面能打开的域名。

人从局域网地址打开面板时，卡片用局域网地址。人从公网域名打开面板时，卡片用远程地址。远程地址留空时，卡片始终用局域网地址。

卡片副标题仍是你写的描述。没有描述时，副标题是当前会打开的那个地址。
